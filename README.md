# Математический квест

Сайт статический. Задания и подсказки генерируются непосредственно в браузере через Gemini Interactions API (`gemini-3.8-flash`).

## Настройка

1. Создайте API-ключ в [Google AI Studio](https://aistudio.google.com/apikey).
2. Откройте `script.js` и замените `PASTE_YOUR_GEMINI_API_KEY_HERE` в `GEMINI_API_KEY` на свой ключ.
3. Опубликуйте файлы проекта на статическом хостинге.

**Важно:** браузерный ключ нельзя скрыть. Посетитель сайта сможет найти его в исходном коде или сетевых запросах. Используйте отдельный ключ только для этого сайта, настройте ограничения ключа по HTTP referrer и API в Google Cloud/AI Studio, а также лимиты расходов. Не используйте ключ с доступом к другим сервисам и отзовите его, если он стал публично доступен. Для ограничения использования ключа задайте разрешённые адреса вашего статического сайта; локальный `file://` может не подходить для проверки ограниченного ключа.
